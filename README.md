☕ Brew Haven / Cafe Area — Fine Dining & Coffee Experience
A visually stunning, modern, and fully responsive website designed for a luxury cafe experience. Built with clean semantic HTML, modern styling, and interactive JavaScript features.

Responsive Sticky Navigation: Smooth scrolling and dynamic mobile navigation drawer.

Table Reservation System: Interactive reservation form with validation and confirmation dynamic feedback.

Lightbox Ambiance Gallery: High-definition photography with lightbox visual previews.

Clean Code Architecture: Structured modular architecture adhering to modern web development standards.
